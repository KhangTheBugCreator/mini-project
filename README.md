# Mini Shopping Cart

A simple mini shopping cart website built with **HTML**, **CSS**, and **JavaScript**.  
This project allows users to add products to the cart, increase/decrease quantity, remove items, and calculate the total price automatically.

---

## 📸 Project Overview

This project includes:

- Product list display
- Add product to cart
- Increase quantity
- Decrease quantity
- Remove product
- Automatic total price calculation
- Simple responsive layout

---

## 📂 Project Structure

```bash
├── index.html
├── style.css
└── lib.js
```

- `index.html` → Main structure of the website
- `style.css` → Styling and layout design
- `lib.js` → Shopping cart logic and functionality

---

## 🚀 Features

### 🛍 Product List

Display available food products such as:

- Phở
- Bánh Mì
- Bún Nước Lèo

Each product contains:

- Name
- Price
- Add To Cart button

---

### 🛒 Shopping Cart

Users can:

- Add products into cart
- Increase quantity using `+`
- Decrease quantity using `-`
- Remove products completely
- View total price in real-time

---

## ⚙️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or libraries are used.

---

## 🧠 Main JavaScript Functions

### `renderProduct()`
Displays all products on the webpage.

### `addToCart(id)`
Adds selected product into cart.

### `renderCart()`
Renders cart items and calculates total price.

### `increaseQuantity(id)`
Increases quantity of a product.

### `decreaseQuantity(id)`
Decreases quantity of a product.

### `removeItem(id)`
Removes product from cart.
